# datapod-for-react-php-json

This is a simple datapod template for a local site that displays data from a JSON file, which is created by a PHP script that parses a text file.

## Install Rust

- Ubuntu
    - https://www.rust-lang.org/tools/install
    - copy/paste command
    - custom installation
    - `rustc --version`
- or look into [Rustup](https://www.rust-lang.org), kind of like nvm for Node

## Compatibility

- ✔️ tested on Ubuntu


## Develop notes

### How create a new module

- create src/bin/developer/learn.rs
- cd scripts
- `cargo add learn`
